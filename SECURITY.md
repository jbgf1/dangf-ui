# Security policy

## Supported versions

Security fixes are provided for the latest published version of `dangf-ui`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for `jbgf/dangf-ui`. Include reproduction steps, affected versions, expected impact, and any known mitigation.

The maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.
